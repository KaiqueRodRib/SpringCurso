# Curso de Spring Boot

Este projeto foi desenvolvido apenas para fins de estudo durante um curso de **Spring Boot**.

Objetivo

O objetivo deste projeto é praticar os principais conceitos do Spring Boot, como:

- Criação de APIs REST;
- Controllers;
- Services;
- Repositories;
- Spring Data JPA;
- Persistência de dados.

Banco de Dados

Este projeto utiliza o **H2 Database** em memória.

Como o banco é executado em memória, todos os dados são perdidos quando a aplicação é encerrada. Seu uso é apenas para facilitar o desenvolvimento e os testes durante o curso.

Tecnologias Utilizadas

- Java
- Spring Boot
- Spring Data JPA
- H2 Database
- Maven
- Lombok

Observação

Este repositório possui finalidade exclusivamente educacional e foi criado para acompanhar os estudos e exercícios realizados durante o curso de Spring Boot.
