Curso de Spring Boot

Este projeto foi desenvolvido apenas para fins de estudo durante um curso de Spring Boot.

Objetivo

O objetivo deste projeto é praticar os principais conceitos do Spring Boot, como:

Criação de APIs REST;
Controllers;
Services;
Repositories;
Integração com Spring Data JPA;
Persistência de dados.
Banco de Dados

Este projeto utiliza o H2 Database em memória.

Por ser um banco em memória, todos os dados são apagados quando a aplicação é encerrada. Ele foi escolhido apenas para facilitar o desenvolvimento e os testes durante o curso, não sendo destinado para uso em produção.

Tecnologias Utilizadas
Java
Spring Boot
Spring Data JPA
H2 Database
Maven
Lombok
Observação
